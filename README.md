## Run locally
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Hosting
The website can be hosted on GitHub Pages, Netlify, Vercel, AWS S3, Cloudflare Pages, cPanel, or any standard web server.

Before production launch, confirm the final domain, connect the enquiry form to a backend or form service, and add final Privacy Policy and Terms pages.
